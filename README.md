# AdVyu Website v3 — React + Tailwind

Premium cosmetics-brand aesthetic: ivory, champagne gold, deep espresso. Cormorant Garamond headlines + Inter body. Framer Motion animations throughout.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repo (or drag the folder into vercel.com → Add New → Project).
2. Vercel auto-detects **Vite**. Build command: `npm run build`, output dir: `dist`. No changes needed.
3. Deploy.

Videos live in `public/videos/` and are copied to the build automatically.
